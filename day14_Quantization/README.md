## 📚 주요 학습 내용

### 1. 메인 강의 (`5-2_양자화모델_성능측정_with_llama.cpp(Easy)_r7.ipynb`)
- **양자화 기본 개념**: 비트 정밀도(FP16, Q4 등)와 메모리/속도/품질 트레이드오프
- **추론기 이해**: `llama.cpp`의 역할과 로컬 추론 워크플로우
- **GGUF 포맷**: PyTorch 계열 모델을 `GGUF`로 변환해 추론 가능한 형태로 만드는 이유
- **성능 비교 실험**: 양자화 전/후 모델의 토큰 생성 속도(TPS) 및 응답 품질 비교

### 2. 실습·과제 공통 핵심
- **모델 준비**: 동일 베이스 모델의 `FP16`/`Q4_K_M` 파일 준비
- **추론 환경 구성**: `llama-cpp-python` 설치 및 모델 로드
- **벤치마크 측정**: 동일 프롬프트로 속도/응답 결과 비교
- **해석 및 보고**: 품질 유지 범위와 자원 절감 효과를 함께 해석
